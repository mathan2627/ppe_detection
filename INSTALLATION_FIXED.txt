ISSUE FIXED: "pip is not recognized" error

CAUSE: pip was not in PATH after activating virtual environment

SOLUTION: Changed all pip commands to use "python -m pip"

================================================================================
                    WHAT WAS CHANGED
================================================================================

Before:
  pip install package

After:
  python -m pip install package

This works even if pip is not in PATH because it uses Python's module system.
