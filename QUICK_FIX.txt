================================================================================
                    QUICK FIX FOR "FILE IN USE" ERROR
================================================================================

ERROR: "The process cannot access the file because it is being used"

CAUSE: Virtual environment (backend\venv) is being used by another process

================================================================================
                    SOLUTION 1: CLOSE EVERYTHING (RECOMMENDED)
================================================================================

1. Close ALL Command Prompt windows
2. Close ALL Python applications
3. Close any terminals or IDEs using the project
4. Wait 10 seconds
5. Run: 1_INSTALL_EVERYTHING.bat again

================================================================================
                    SOLUTION 2: USE FIX SCRIPT
================================================================================

Run this file:

    FIX_VENV_LOCKED.bat

This will:
  • Kill all Python processes
  • Remove locked venv
  • Allow you to reinstall

Then run: 1_INSTALL_EVERYTHING.bat

================================================================================
                    SOLUTION 3: RESTART COMPUTER
================================================================================

If above solutions don't work:

1. Restart your computer
2. Run: 1_INSTALL_EVERYTHING.bat
3. Don't open multiple terminals

================================================================================
                    SOLUTION 4: USE EXISTING VENV
================================================================================

If venv already exists and works:

When running 1_INSTALL_EVERYTHING.bat:
  • It will ask: "Do you want to recreate it? (y/n)"
  • Type: n
  • Press Enter
  • It will use existing venv and just update packages

================================================================================
                    PREVENTION
================================================================================

To avoid this error:
  • Close all terminals before running installation
  • Don't run multiple installations at once
  • Don't open project in IDE during installation
  • Let installation complete fully

================================================================================
                    QUICK STEPS
================================================================================

1. Close all Command Prompt windows
2. Run: FIX_VENV_LOCKED.bat
3. Run: 1_INSTALL_EVERYTHING.bat
4. When asked "recreate?", type: n (to use existing)

OR

1. Restart computer
2. Run: 1_INSTALL_EVERYTHING.bat
